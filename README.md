# Маршрут — планировщик путешествия

Красивое адаптивное веб-приложение для подготовки к поездке. Проект показывает основные данные о путешествии: маршрут по дням, бюджет, бронирования, чек-лист подготовки и ближайшие действия.

Это учебный проект. Все даты, суммы, адреса и бронирования — демонстрационные данные.

## Демонстрационная поездка

- Название: «Лиссабон и океан».
- Даты: 12–18 сентября, 7 дней.
- Маршрут: Лиссабон → Кашкайш → Синтра → Эрисейра → океан → Лиссабон.
- Общий бюджет: 180 000 рублей.

## Текущий пользователь

Проект ориентирован на путешественника, который готовит поездку самостоятельно: ищет маршрут, следит за бюджетом, подтверждает бронирования и собирает вещи по чек-листу. Интерфейс рассчитан на использование и с компьютера, и с телефона.

## Основные функции

1. **Обложка поездки** — название, даты, количество дней, обратный отсчёт и декоративная линия маршрута (CSS-градиенты и встроенный SVG, без внешних изображений).
2. **Темп путешествия** — переключатель «Спокойно» / «Насыщенно», который меняет расписание, стоимость дня, подсказку и общий прогноз расходов.
3. **Маршрут по дням** — выбор дня и просмотр событий: город, дата, время, название, категория, стоимость, статус бронирования.
4. **Бюджет** — общий бюджет, запланированная сумма, остаток, прогресс и категории расходов.
5. **Бронирования** — карточки перелёта, отеля, поезда и экскурсии с кнопкой «Подтвердить» и уведомлением.
6. **Чек-лист подготовки** — категории «документы», «деньги», «вещи», «здоровье»; отметки сохраняются в `localStorage`.
7. **Мобильный режим «Сегодня»** — на узких экранах акцент на текущий день, ближайшее событие и следующую задачу, с нижней навигацией.
8. **Состояния интерфейса** — `loading` (скелетоны), `error` (с кнопкой «Повторить»), `empty` и `success`, плюс панель «Демо состояний».

## Образ результата

Готовое приложение — набор страниц-экранных блоков в одном `index.html`. Пользователь видит:

- единую сводку по поездке с карточками на светлом тёплом фоне;
- интерактивные секции без перезагрузки страницы;
- уведомления (toast) после действий;
- сохранение состояния после перезагрузки страницы;
- запрет горизонтальной прокрутки на контрольных ширинах 1440, 768 и 390 px.

Визуальный стиль: белые карточки со скруглением 18–24 px, мягкие тени, темно-синий основной текст, фиолетовый главный акцент, дополнительные морской синий и коралловый, зелёный/жёлтый/красный для статусов.

## Технологии

- **HTML** — семантическая разметка (`app/index.html`).
- **CSS** — адаптивная вёрстка, сетки, градиенты, скелетоны (`app/styles.css`).
- **JavaScript** — логика данных, рендеринг, состояние, `localStorage` (`app/app.js`).

Без фреймворков, сборщиков, npm, внешних библиотек, CDN, баз данных, авторизации и внешних API. Работает при обычном открытии `app/index.html` в браузере.

## Запуск

Откройте `app/index.html` в браузере. Интернет не требуется.
